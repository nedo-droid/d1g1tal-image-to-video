# D1G1TAL Image-to-Video Pipeline

> **Developed by D1G1TAL**, supported by **Blue Screen Studios**

This repository documents the progress, code, and assets for an image-to-video generation pipeline, developed iteratively using AI assistance (ChatGPT sandbox).

## 📂 Repository Structure

- `src/` — Python scripts, generation code, and pipeline logic.
- `assets/` — Input images, segmentation masks, overlays, and generated frames.
- `configs/` — JSON configuration files for scenes and sketches.
- `docs/` — Detailed documentation, prompts, and iteration notes.

##  Progress & Iterations

*Tracking the evolution of the pipeline:*

- **v17**: Initial sandbox setup, mask generation, environment configuration, and manual pipeline implementation.
  - Generated masks and overlays for logo refinement.
  - Environment-only frames at t=0.0 and t=2.0.
  - Scene configurations for eagle and palm sketches.
